# C# Windows Forms - Not Ortalama Hesaplama Aracı 📚

Bu proje, C# Windows Forms kullanarak geliştirdiğim, bir öğrencinin ders notlarını girerek genel ortalamasını hesaplamasını sağlayan masaüstü uygulamasıdır.

> *Not: Bu proje, 15 yaşındayken C# ve Windows Forms öğrenirken geliştirdiğim uygulamalardan biridir.* 🎮

## 🚀 Özellikler
* Öğrenci adı girişi.
* Matematik, Türkçe, Fizik, Kimya, Felsefe, Biyoloji, Tarih, Coğrafya, Din Kültürü ve Yabancı Dil olmak üzere geniş ders listesi.
* Girilen notlara göre anlık ortalama hesaplama mekanizması (`buttonOrtalamaHesaplama`).
* Şık ve kullanıcı dostu arayüz tasarımı.

## 🛠️ Kullanılan Teknolojiler
* C#
* .NET / Windows Forms

## 💡 Nasıl Çalıştırılır?
1. Projeyi Visual Studio ile açın.
2. `Form1.cs` dosyasını derleyip çalıştırın.
3. İlgili derslerin notlarını girip "Ortalama Hesapla" butonuna basın!
